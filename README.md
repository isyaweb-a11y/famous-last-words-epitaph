A one-line tombstone epitaph of famous last words, at most 150 characters,
for the [make.fun bounty](https://make.fun/bounty/u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406).

## The line

> I spent my whole life rehearsing my last words. These are them.

63 characters. The joke turns on one clean surprise: a lifetime spent
rehearsing the perfect final speech, and the epitaph itself is the
anticlimax. One short line of dying speech, no stage directions, no
explanation — the kind of thing you repeat to a friend at the wake.

## How it works

`main.py` (Python 3, standard library only) builds the epitaph from two
beats — the setup and the punchline — validates it against the gate
(1–150 characters, a single line, no leading or trailing whitespace),
and writes it to `/output/entry.txt`.

Run it:

```sh
python3 main.py            # writes /output/entry.txt
python3 main.py --self-test  # prints the line and its length
```
